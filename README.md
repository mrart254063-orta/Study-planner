# Study Planner

A simple web app that helps students plan their study time, keep track of deadlines, and see how much they have studied each week.

## Features

- Add subjects and study tasks
- Set deadlines and mark tasks as complete
- Track daily study progress against a daily goal
- See a weekly summary with a bar chart and time per subject
- Data is saved in the browser, so it is still there when you come back

## Built with

- HTML
- CSS
- JavaScript

## How to run

1. Download the files.
2. Open `index.html` in a web browser.

No installation is needed.

## How to use

1. Open the **Tasks** tab and add a subject, such as Math or Biology.
2. Add a task with a subject, a deadline, and the minutes you plan to study.
3. When you finish a task, tap its box to mark it complete.
4. Check the **Today** tab for your daily progress and the **Week** tab for your weekly summary.

Tip: the app starts empty. Add a subject first, then your tasks.
## Files

- `index.html`: page structure
- `style.css`: styling
- `script.js`: app logic
